2.11.0: Mods that change their id (a feed lists the ids a mod had before, "was" in manifest.json) are recognised: a copy installed under its old id shows as an update rather than as an unknown mod beside a new one, the old copy is replaced (or moved aside), and the update finishes with a restart, so the old and new copies never run at the same time.

Keys and passwords in the Mod settings tab (such as AICompanion's Jev ApiKey) are no longer shown in plain text: they appear as dots and the last 4 characters, with Paste to replace one from the clipboard and Show or Hide to see it.

Mods that need a game restart are no longer reloaded mid-game right after the manager updates them, and updating a mod installed in BepInEx/plugins now replaces that copy (it takes effect after a restart) instead of showing Up to date while the old version keeps running. A card now says when an older version than the one on disk is still running.

Fixes the Mod settings tab only listing Script Engine: it now finds every running mod (BepInEx keeps them on a hidden object that the first search skipped). Lists each mod with its number of settings, with a Settings button on its card.
