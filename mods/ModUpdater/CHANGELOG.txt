2.13.0: Auto update. Switch it on for a mod in My mods, and turn on 'Update mods automatically' in the Manager tab: every few minutes (5 by default, at least 2) the manager looks for new versions of those mods and updates them one at a time, 20 seconds apart, the manager itself last. Mods that need a restart are downloaded and wait for it. Only installed, switched-on mods are touched (nothing new is installed, nothing downgraded, disabled mods stay off), and nothing runs on a loading screen, while dead, teleporting or in a cutscene. The timed look reads only each source's manifest.json from raw.githubusercontent.com (not counted against GitHub's 60-requests-an-hour limit without a login, and with an ETag); a full check only follows a real new version, and a 403/429 pauses automatic checks (doubling, up to an hour, or as long as GitHub asks).

2.12.0: A mod waiting for a game restart can be reloaded anyway: Force on its card (or Force reload in its settings), then Sure? within 5 seconds. A warning says what can go wrong (a mod that adds pieces or items can lose some in areas that load while it reloads: safest in a test world). Not offered for a copy in BepInEx\plugins, or while an older copy under the mod's old id is still running.

2.11.0: Mods that change their id (a feed lists the ids a mod had before, "was" in manifest.json) are recognised: a copy installed under its old id shows as an update rather than as an unknown mod beside a new one, the old copy is replaced (or moved aside), and the update finishes with a restart, so the old and new copies never run at the same time.

Keys and passwords in the Mod settings tab (such as AICompanion's Jev ApiKey) are no longer shown in plain text: they appear as dots and the last 4 characters, with Paste to replace one from the clipboard and Show or Hide to see it.

Mods that need a game restart are no longer reloaded mid-game right after the manager updates them, and updating a mod installed in BepInEx/plugins now replaces that copy (it takes effect after a restart) instead of showing Up to date while the old version keeps running. A card now says when an older version than the one on disk is still running.

Fixes the Mod settings tab only listing Script Engine: it now finds every running mod (BepInEx keeps them on a hidden object that the first search skipped). Lists each mod with its number of settings, with a Settings button on its card.
